周年記念 メイドさんアクキーガチャ 説明書
========================================

1. このアプリについて
--------------------
店舗の周年イベントで使用する、iPad縦向き用のWebガチャアプリです。
ご主人様が「ガチャを回す！」ボタンを押すと、メイドさんのアクキー画像がランダムで1つ当たります。

画像や効果音ファイルがまだ入っていない状態でも、CSSで作った仮のガチャマシンと仮表示で動作します。


2. 起動方法
----------
index.html をブラウザで開いてください。

GitHub Pagesで公開した場合は、公開URLをiPad Safariで開いて使用します。

iPadは縦向きで使用してください。
横向きになると「iPadを縦向きにしてお楽しみください」と表示され、ガチャを開始できません。


3. 基本操作
----------
1. 待機画面で「ガチャを回す！」を押します。
2. ボタン押下時に抽選結果が1回だけ確定します。
3. ハンドル回転、カプセル攪拌、排出、開封演出が再生されます。
4. 当たったメイドさんのアクキー画像とメッセージが表示されます。
5. 続けて同じご主人様が回す場合は「もう一度ガチャを回す」を押します。
6. ご主人様を交代する場合は「次のご主人様」を押し、確認後に履歴をリセットします。

演出中は連打しても二重抽選されません。


4. スキップ機能
--------------
演出開始から約1秒後に「演出をスキップ」ボタンが表示されます。

スキップしても抽選結果は変わりません。
スキップ時も履歴には1回分だけ登録されます。

初期状態ではスキップ機能はONです。
管理者設定からON/OFFを切り替えできます。


5. 管理者設定
------------
待機画面上部のタイトル部分を5回連続でタップすると、管理者設定が開きます。

管理者設定で確認・変更できる内容:
- 登録されているメイドさんの人数
- 登録されているメイドさんの名前
- 効果音 ON/OFF
- スキップ機能 ON/OFF
- 現在のご主人様のガチャ回数
- 履歴削除
- 演出テスト


6. メイドさんの追加・削除
------------------------
config.js を編集します。

例:

const maidConfig = [
  {
    id: "maid01",
    name: "ひなた",
    image: "img/maids/maid01.png"
  },
  {
    id: "maid02",
    name: "みるく",
    image: "img/maids/maid02.png"
  }
];

追加する場合:
1. img/maids/ にPNG画像を入れます。
2. config.js に1人分の設定を追加します。

削除する場合:
config.js から対象のメイドさんの設定を削除します。

抽選確率は全員同じです。
同じメイドさんが連続で当たることもあります。


7. メイド画像の推奨仕様
----------------------
形式: PNG
背景: 透過PNG推奨
向き: 縦長
推奨サイズ: 1000 x 1600px 前後
ファイル名: 半角英数字推奨

画像が読み込めない場合は、名前入りの仮カードが表示されます。


8. ガチャマシン素材
------------------
以下の場所に画像を置くと、CSSの仮表示から画像表示に差し替わります。

img/gacha/
  machine_body.png
  machine_window.png
  handle.png
  capsule_red.png
  capsule_blue.png
  capsule_yellow.png
  capsule_pink.png
  capsule_closed.png
  capsule_top.png
  capsule_bottom.png

素材が無い場合でもアプリは動作します。


9. 効果音素材
------------
以下の場所に音声ファイルを置くと、演出タイミングに合わせて再生されます。

audio/
  tap.mp3
  gacha_start.mp3
  click.mp3
  capsule_drop.mp3
  capsule_hit.mp3
  charge.mp3
  capsule_open.mp3
  sparkle.mp3
  result.mp3

音声ファイルが無い場合や、iPad Safariで再生に失敗した場合でも、ガチャ演出は止まりません。


10. 履歴について
---------------
履歴は現在のご主人様の分だけ保存されます。
ページを再読み込みしても履歴は残ります。

「次のご主人様」を押して確認すると、現在の履歴が削除され、回数が0に戻ります。


11. GitHub Pagesで公開する場合
-----------------------------
1. GitHubのリポジトリを開きます。
2. Settings を開きます。
3. Pages を開きます。
4. Branch を master にします。
5. フォルダは /root を選びます。
6. Save を押します。
7. 表示されたURLをiPad Safariで開きます。


12. 当日の運用チェック
---------------------
イベント開始前に以下を確認してください。

- iPadを縦向きにして表示が崩れない
- 「ガチャを回す！」を押すと演出が始まる
- ハンドルが回転する
- カプセルが動く
- 結果画面にメイドさんが表示される
- 結果メッセージが表示される
- 連打しても二重抽選されない
- スキップしても結果が変わらない
- 履歴が1回につき1件だけ増える
- 「次のご主人様」で履歴を削除できる
- 効果音ON/OFFが切り替わる


13. トラブル時
-------------
メイドさんが表示されない:
config.js の image のパスと、実際の画像ファイル名を確認してください。

ガチャに登録されているメイドさんがいないと表示される:
config.js の maidConfig に1人以上登録してください。

音が鳴らない:
audio フォルダにmp3ファイルがあるか確認してください。
iPadの消音モードや音量も確認してください。

横向きの案内が出る:
iPadを縦向きに戻してください。

履歴を消したい:
待機画面の「次のご主人様」を押してください。
